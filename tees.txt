#  TEE ADVENTSKALENDER – HIER DIE TEES EINTRAGEN
# ============================================================
#
#  So funktioniert es:
#  - Jedes Türchen hat einen Block, der mit "Türchen 1", "Türchen 2" usw. beginnt.
#  - Darunter stehen die Angaben, immer als  "Feld: Text".
#  - Einfach den Text hinter dem Doppelpunkt überschreiben.
#  - Zeilen, die mit # beginnen, sind Notizen und werden ignoriert.
#
#  Die Felder:
#    Name:          Name des Tees
#    Beschreibung:  kurzer Text zum Tee
#    Zubereitung:   z. B. "2 EL auf 1 l heisses Wasser, 5–8 min"
#    Haltbar bis:   z. B. "31.01.2028"
#    Bild:          Dateiname aus dem Ordner "images"
#                   (weglassen = Tee01_V1.webp, Tee02_V1.webp usw.)
#
#  Ein Feld darf leer bleiben. Die Reihenfolge der Blöcke ist egal.
# ============================================================
